# mizcode-reviewer

mizcode-reviewer lets your AI coding tool (Claude Code or Codex) post its pull request reviews as a bot, for example `acme-review[bot]`, instead of under your own GitHub account.

- The AI review runs on your machine with your own AI subscription.
- The server does one thing: it takes a finished review and posts it to GitHub as your GitHub App.
- You run your own copy on your own AWS account.

## Status

Early development. Nothing works end to end yet.
